Bosque Cinema · Demo de integración PostgreSQL + MongoDB

Cada botón llama a la API, que a su vez usa el script de integración del equipo y muestra la respuesta tal cual. Documentación completa en /docs.

Estado de los motores

Comprueba PostgreSQL (Neon) y MongoDB (Atlas).

Caso 1 · Función completa

Función y ventas (PostgreSQL) + requisitos, reseñas e incidentes (MongoDB).

Caso 2 · Película con requisitos

Película y funciones (PostgreSQL) + ficha y requisitos (MongoDB).

Caso 3 · Ventas vs incidentes por sala

Boletas e ingresos (PostgreSQL) cruzados con incidentes (MongoDB). Vacío = todas las salas.

Caso 4 · Historial del espectador

Compras (PostgreSQL) + reseñas y quejas (MongoDB).

Transacción entre motores · Devolución de una venta por queja

La venta pasa a ANULADA en PostgreSQL y se crea la queja con el reembolso en MongoDB. Si un motor falla, el otro se deshace. Modifica datos (venta de demo: 31, 32 o 33; cada una solo se puede devolver una vez).

Prueba también un id inexistente (9999), una venta ya anulada o un motivo de menos de 5 letras para ver los errores.
